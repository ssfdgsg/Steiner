# Repository metadata

Copy the following values into the repository host's **About** settings when creating the remote repository.

| Field | Value |
| --- | --- |
| Repository name | `Steiner` |
| Description | OpenAI-compatible L7 gateway for vLLM and SGLang with metrics-driven, cache-aware LLM inference routing. |
| Website | Leave empty until a public documentation or demo site is available. |
| Topics | `llm`, `ai-gateway`, `inference`, `vllm`, `sglang`, `openai-compatible`, `load-balancer`, `kubernetes`, `prometheus`, `opentelemetry`, `golang` |

Recommended repository settings:

- Set the default branch to `main` and require pull-request review plus passing CI before merging.
- Enable private vulnerability reporting and Dependabot alerts.
- Enable squash merging; keep merge commits and rebase merging disabled for a linear history.
- Add a repository social-preview image once branding assets are available.
